PROJECT: ORBIT BUG TRACKER VERCEL: orbit-fontend.vercel.app RENDER: orbit-backend-i2rz.onrender.com REPO: theshydev/bug-tracker

01 System Topology & Core Tech Stack

ORBIT is an enterprise-grade, AI-assisted bug tracking engine designed as a decoupled full-stack monorepo. It features autonomous AI bug triage, semantic deduplication, and federated OAuth 2.0 authentication.

Frontend Runtime

React 19 (Vite 5) with single-page routing, client-side JWT authorization guards, responsive theme toggling, and zero-radius neo-brutalist components.

Backend Architecture

Node 24 & Express 4 configured with native ES Modules (type: module), immediate unblocked HTTP server boot, and dynamic CORS origin resolution.

Database & Models

MongoDB Atlas accessed via Mongoose 8. Includes custom URI sanitizers and 8.8.8.8 DNS resolver fallbacks to prevent SRV timeouts.

02 Academic Research Gaps Implemented

Implemented directly to solve structural challenges presented in: "Past, Present, and Future of Bug Tracking in the Generative AI Era" (arXiv:2510.08005v2).

Research Paper Gap Technical Challenge ORBIT Solution Status
1. Automated Triage Manual assignment of priority and categorization is error-prone. Gemini API zero-shot analysis suggests priority (low/med/high), structured description, and tags. RESOLVED
2. Duplicate Detection Redundant issues overwhelm maintainers and fracture discussions. Parallel semantic similarity scan against 20 open project bugs returning similarity % and match reasoning. RESOLVED
3. Static Reports Reports do not adapt as symptoms and user discussions develop. On-demand re-triage endpoint (POST /api/bugs/:id/retriage) to continuously re-evaluate bugs. RESOLVED

6. Communication Silos Conversations fracture into external chat clients. Threaded contextual comments (Comment model) directly bound to bug IDs. RESOLVED

1. Resilient Server Initialization (server/server.js)

Addresses asynchronous dependency bottlenecks. The HTTP listener is invoked immediately so reverse proxies (like Render) immediately recognize the service as live:

// 2. DNS Fallback for Windows & ISP SRV Lookup timeouts

} catch (e) {}

// 3. Connect to MongoDB using sanitized URI
connectDB();

2. Mongo URI Sanitization (sanitizeMongoUri)

Eliminates crashes when passwords contain special characters (e.g. SrZF_F"2:=*Pa9J):

export const sanitizeMongoUri = (rawUri) => {
  if (!rawUri) return rawUri;
  let uri = rawUri.trim().split(/\s+/)[0]; // Strip trailing pasted text
  const match = uri.match(/^(mongodb(?:\+srv)?:\/\/)([^:]+):(.*)@([^/?#]+)(.*)$/);
  if (match) {
    const [, protocol, username, rawPassword, host, rest] = match;
    let decoded = rawPassword;
    try { decoded = decodeURIComponent(rawPassword); } catch {}
    const safePassword = encodeURIComponent(decoded);
    let safeRest = rest;
    if (!safeRest || safeRest === '/' || safeRest === '') {
      safeRest = '/bugtracker?retryWrites=true&w=majority';
    }
    return `${protocol}${username}:${safePassword}@${host}${safeRest}`;
  }
  return uri;
};

3. Express Middleware Pipeline (server/src/app.js)

Double Prefix Elimination Middleware

If an API client prefixes /api onto a base URL that already ends with /api, incoming requests for /api/api/auth/google are automatically rewritten to /api/auth/google before hitting the router.

// Dynamic CORS Resolution
const allowedOrigins = [
  'https://orbit-fontend.vercel.app',
  'http://localhost:5173',
  'http://localhost:5000',
  process.env.CLIENT_URL,
].filter(Boolean);

app.use(cors({
  origin: (origin, callback) => {
    if (!origin || allowedOrigins.includes(origin) || origin.endsWith('.vercel.app')) {
      return callback(null, true);
    }
    return callback(null, true); // Permissive fallback
  },
  credentials: true,
}));

// Route Normalization
app.use((req, res, next) => {
  if (req.url.startsWith('/api/api/')) {
    req.url = req.url.replace(/^\/api\/api\//, '/api/');
  }
  next();
});

05 Complete REST API Registry

Method Endpoint Auth Guard Function & Payload
POST /api/auth/register Public Registers user with Bcrypt-10 hashed password. Returns 1d JWT.
POST /api/auth/login Public Authenticates email/password via bcrypt.compare. Returns 1d JWT.
GET /api/auth/google Public Passport Google OAuth 2.0 trigger (scopes: profile, email).
GET /api/auth/google/callback Public OAuth callback. Issues JWT and redirects to frontend with URL hash.
GET /api/projects Bearer Token Fetches all user projects.
POST /api/projects Bearer Token Creates a new project ({ name, description }).
GET /api/projects/:projectId/bugs Bearer Token Lists all bugs in a project, populated with assignee data.
POST /api/projects/:projectId/bugs Bearer Token AI Trigger: Concurrently runs Gemini triage & duplicate detection.
PUT /api/bugs/:id Bearer Token Updates status (open, in-progress, resolved, closed) or priority.
PUT /api/bugs/:id/assign Admin Only Assigns issue to user: { assignedTo: userId }.
POST /api/bugs/:id/retriage Bearer Token On-Demand AI: Re-runs Gemini triage on existing issue.
GET /api/bugs/:bugId/comments Bearer Token Fetches discussion comments for an issue.
POST /api/bugs/:bugId/comments Bearer Token Adds comment: { text }.

06 Authentication & OAuth 2.0 Handshake

ORBIT implements both local JWT authentication (using bcryptjs with salt rounds of 10) and federated OAuth 2.0 through Passport.js.

Security Architectural Invariant: Hash Fragment Token Transfer

After successful OAuth authentication, the server redirects to ${clientUrl}/oauth-callback#token=${jwt}&user=${encodedJson}. Because parameters are placed behind the URL hash fragment (#) rather than a query string (?), they are never transmitted to web servers in HTTP request headers or stored in proxy access logs.

07 Gemini AI Pipeline (@google/genai)

Implemented in server/src/utils/aiService.js utilizing the official Google GenAI SDK and modern ai.interactions.create API with model gemini-4-hydrogen.

1. Automated Triage Engine (triageBug)

export const triageBug = async (title, description) => {
  try {
    const prompt = `You are an expert software engineering bug triage assistant.
Analyze this bug report and return a JSON object with:
- "suggestedPriority": one of "low", "medium", or "high"
- "tags": an array of 2-4 short category tags (e.g., "ui", "auth", "performance", "data-loss", "crash")
- "enhancedDescription": concise, structured version of the description (max 2 sentences).
- "reasoning": one sentence explaining why you chose that priority.

Bug Title: ${title}
Bug Description: ${description || '(no description provided)'}

Respond ONLY with valid JSON.`;

    const interaction = await ai.interactions.create({
      model: 'gemini-4-hydrogen',
      input: prompt,
      store: false,
    });

    const jsonText = interaction.output_text?.trim()
      .replace(/^```json?\s*/i, '').replace(/```\s*$/i, '');
    return JSON.parse(jsonText);
  } catch (err) {
    // Graceful fallback: Never block bug creation if AI service fails
    return { suggestedPriority: null, tags: [], enhancedDescription: null, reasoning: null };
  }
};
